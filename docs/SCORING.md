# Scoring

## Text normalization (`text.py`)

Devanagari makes "the same string" ambiguous, so normalization is explicit and minimal.

| Level | Applied | Used by |
|---|---|---|
| `canonical` | Unicode **NFC**, every whitespace run (incl. NBSP, U+202F) → one space, trim | CER, WER, NED, exact match, all structured scorers |
| `loose` | canonical + drop ZWJ/ZWNJ/ZWSP + replace punctuation (Unicode `P*` and `।` `॥` `॰`) with space + casefold | `loose_match`, OCRBench-style containment, abstention detection |

NFC matters even though the generator's ground truth is already NFC: model output is not,
and a decomposed nukta (`क` + `़`) vs the precomposed form (`क़`) would otherwise count as an
error. Digits and orthography are **not** folded (४२ ≠ 42) — the same rule the
nepal-pixel-synthesis grounding check uses.

Before scoring, model output is cleaned of reasoning (`<think>…</think>`; an unclosed
`<think>` from a truncated reply drops everything after it; a lone `</think>` left by a chat
template that opened the tag in the prompt drops everything before it), a code fence wrapping
the whole reply, and `<|endoftext|>`.

## Transcription metrics (`metrics.py`)

| Metric | Definition |
|---|---|
| `cer` | char edit distance / reference length, on Unicode code points. Unbounded (insertions count). |
| `acer` | **akshara** error rate: the same edit distance over aksharas (what a reader sees as one character: a consonant cluster with its vowel signs counts as one), zero-width characters ignored. One wrong vowel sign costs one unit, not a fraction of one: `किताब`→`कताब` is `cer` 0.20 but `acer` 0.33; `विद्यालय`→`विदयालय` is 0.12 vs 0.50. Opt in by adding `acer` to a benchmark's `metrics:`. |
| `char_accuracy` | `max(0, 1 − cer)` per sample. **Headline** for transcription: bounded, so one hallucinated paragraph on a one-word image cannot dominate the mean. |
| `wer` | word edit distance / reference words; words split on whitespace only, so `ल्यायो।` ≠ `ल्यायो` |
| `wer_loose` | `wer` on the `loose` text: punctuation (danda included), zero-width characters and case are ignored |
| `ned` | edit distance / max(len) ∈ [0, 1] (OmniDocBench-style) |
| `exact_match` / `loose_match` | canonical / loose equality |
| `length_ratio` | prediction length / reference length (truncation & hallucination signal) |
| `anls`, `relaxed_accuracy`, `contains_match` | DocVQA ANLS (τ=0.5), ChartQA 5% numeric tolerance, OCRBench containment |

When a sample has several references, `cer`, `acer`, `wer`, `wer_loose` and `ned` score the best one (lowest error), as `exact_match` and `loose_match` already do.

Errored samples get the worst value of every metric. Aggregates are means; the headline
metric gets a 1000-resample percentile-bootstrap 95% CI (seeded, deterministic). When every
sample carries a `doc_id` in its meta (the NepaliPixel docs benchmarks do; a dataset can list
a `doc_id` column under `meta:`), whole documents are resampled instead of single samples:
pages of one document and questions on one page are correlated, and treating them as
independent makes the interval too narrow. Point estimates are unchanged.

## Document scorers (`structured.py`)

Against nepal-pixel-synthesis labels (`docs.py` reads the generator's output directory).

**Key-value** (`nepalipixel-docs-kv`). The model gets the document image and the list of
canonical field ids and returns JSON. Gold and predicted (field_id, value) pairs are
compared as multisets after canonical normalization: `kv_precision`, `kv_recall`,
**`kv_f1`**. `kv_value_sim` is the mean best similarity of each gold value under its key
(partial credit view), `kv_doc_exact` whether the whole document is right, `kv_parse_ok`
whether JSON was found. Repeated fields accept a list or a comma-separated string. Image
fields (value `" "`) are not scored.

**QA** (`nepalipixel-docs-qa`). One question per sample, including unanswerable ones
generated by extraction blocking (answer region painted out; gold `ANSWER NOT PRESENT`).
**`qa_score`** = ANLS on answerable questions, 1/0 for correctly abstaining on unanswerable
ones. The two failure modes are reported separately: `anls_answerable`,
`false_abstention` (refused an answer that is on the page), `abstention_accuracy`
(abstained when it should). Metrics that do not apply to a sample are left out of that
metric's mean.

Abstaining means replying with the exact string `ANSWER NOT PRESENT`, and the prompt says so
("If the answer is not on the page, reply exactly: ANSWER NOT PRESENT"); case, punctuation and
surrounding words do not matter. `qa_score` and `abstention_accuracy` use only that, so they
partly measure instruction following. `abstained_loose` (unanswerable questions only) also
counts a refusal in other words, in Nepali (`उत्तर उपलब्ध छैन`, `उल्लेख छैन`, `फेला परेन`, …)
or English (`not present`, `cannot find`, `not mentioned`, …). A gap between
`abstained_loose` and `abstention_accuracy` is a model that refuses correctly but not in the
required words; a low `abstained_loose` is a model that invents answers. Note: the generator emits no negatives for `--split benchmark` unless
`--extraction-blocking N` is passed.

**Page + reading order** (`nepalipixel-docs-page`). Gold blocks are the page's regions in
`order_rank` order (the page `text`, one line per region, `[LOGO]` stripped).
**`char_accuracy`**/`cer` on the joined page text. `reading_order`: each gold block is
aligned to its most similar unused prediction line (similarity ≥ 0.5); Kendall's τ of
the matched positions, mapped to [0, 1]. `block_recall`: share of blocks found.

**Tables** (`nepalipixel-docs-table`). Each `structured_table` region is cropped (+8 px) and
the gold table rebuilt from its `table_cell` regions (row, col, spans) with cell text from
the words whose `field` belongs to the cell. **`teds`**: Tree-Edit-Distance Similarity
(Zhong et al. 2020) — Zhang–Shasha over `table/tr/td`, rename cost 1 for different spans,
normalized text edit distance for same-span cells. `teds_struct` ignores text. HTML is
parsed leniently (unclosed tags, `th`); a markdown table is accepted too.

**Layout** (`nepalipixel-docs-layout`). Regions except `table_cell`/`table_row`, statuses
`rendered`/`non_text`/`clipped`, boxes from `regions_norm`. The model returns
`[{"role", "bbox"}]` on a 0–1000 grid. Greedy one-to-one matching by IoU ≥ 0.5:
**`layout_f1`** requires the role to match, `detection_f1` does not.

## Ranking (`leaderboard.py`)

Per (benchmark, model) the board shows one result: measured beats imported, a full run
beats a subset, then the newest. `rank` = 1 + number of models whose CI lies entirely on
the better side of this model's CI (LMArena convention); `position` = ordinal by point
score. The overview averages a 0–100, higher-is-better mapping of each headline
(`score_100`) and ranks models with complete coverage first.
